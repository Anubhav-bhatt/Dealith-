# Dependency policy

Add a package only for an explicit requirement or an audited defect; reuse existing capabilities. Record purpose, browser/server placement, license, maintenance status, advisory exposure and transitive cost. Exact direct versions plus the frozen pnpm lockfile are the executable dependency baseline; review intentional updates with full affected checks. Node 24 LTS remains the supported runtime line; exact local/container pin is 24.19.0. Compatible updates require a tested lockfile/artifact, not an unreviewed latest tag. [Node release policy](https://nodejs.org/en/about/previous-releases).

One runner (Vitest) covers TypeScript utilities, components and assembled API contracts; Playwright covers browsers; axe tests accessibility. The existing native real-service harness avoids a second database emulation stack; CI uses PostgreSQL/Redis containers. pnpm minimum release age and build-script allowlists reduce uncontrolled install execution. Shared contracts cannot depend on persistence. Production deploy excludes development dependencies; migration tooling is separately packaged.

Run `pnpm audit --prod --audit-level=high` and review the full development graph before a release. Audit output is time-specific evidence and cannot guarantee absence of unknown vulnerabilities. New high/critical findings block affected release until patched or explicitly assessed; never disable the check to obtain PASS. `pnpm security:scan` identifies known credential signatures and personal runtime paths; manually review synthetic local credentials and ignored files separately. No actual provider credentials are required.

Current targeted overrides: Prisma config deepmerge-ts 8.0.0 and Prisma CLI mysql2 3.23.1 (ADR-017); Nest platform-express multer 2.3.0 (ADR-018). Keep scope narrow, document advisory and upstream dependency, run affected integration/build tests, and remove the override once the parent supplies the fix. Tailwind/PostCSS and axe are required UI/style/test foundations; no AI/payment/auth provider SDK is installed for a speculative feature.

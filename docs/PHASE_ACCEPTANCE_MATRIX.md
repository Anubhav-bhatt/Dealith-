Dependencies are cumulative where applicable. A phase may prepare reversible design work while an external dependency is unresolved, but cannot claim the dependent capability or phase exit. Feature flags enforce unavailable behavior server-side. Every deferred item records owner, reason, impact, target and approval when a non-blocking exception is actually accepted. No inferred approval or hidden carryover.
